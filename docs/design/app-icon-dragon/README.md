# UniFeed 启动图标：可爱小龙

三套 Q 版龙形象，暖橙品牌色（`#FF6D00` / `#FF9E40` / `#C43E00`），奶油白龙身。线条粗、块面大，48dp 仍能认脸。无文字。

落地选用 **方案 1：圆润 Q 版小龙**。

## 方案 1 — 圆润 Q 版小龙（主推 / 已落地）

预览：`option-1-chubby.png`（512×512）  
源文件：`option-1-chubby.svg`

形象：坐姿胖龙，短角、小翅膀、笑眯眯闭眼、张嘴笑。龙身奶油白，肚皮浅黄，角尖与翼膜暖橙。

适合做启动图标：脸占比最大、五官对比最强；闭眼笑在小尺寸仍是稳定的「两条弧 + 一个圆嘴」，不会糊成一团。

## 方案 2 — 小龙抱 RSS 球

预览：`option-2-rss.png`  
源文件：`option-2-rss.svg`

形象：同一只小龙抱着经典 RSS 信号球，角旁加两道浅色信号弧。

点出「RSS 阅读器」身份，开眼更精神。小尺寸下 RSS 弧仍可读，脸被球体分走一部分面积。

## 方案 3 — 盘龙 + 小围巾

预览：`option-3-peek.png`  
源文件：`option-3-peek.svg`

形象：身子盘成一团，两只小爪搭在线圈上，奶油围巾带橙条纹，眼睛往上看。

姿态更特别，围巾增加季节感。盘身在 48dp 容易和头连成一块，辨识度低于方案 1。
